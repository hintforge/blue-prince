# Blue Prince -- Controls

**status:** research-integrated
**last_reconciled:** 2026-10-31

No official controls table was found by Stage 0, P1 or P2 (the wiki.gg and Fextralife Controls pages return empty 404 pages, checked again 2026-10-31; see `limitations.md`). Every binding below comes from third-party pages, so treat each as "verify in game" and check the in-game remapping screen. One section per platform; the only platform difference in the guide is controls. Role split with `settings.md`: this file owns the bindings and the history of remapping; `settings.md` lists the menu entries (Accessibility, Motion Assist and the rest). Source numbers in brackets (for example [22]) are listed in `## Sources` at the end; claims whose `_source:` line says P2 use the P2 numbering listed in `## Sources (P2)`.

## Cross-platform facts

The game supports mouse and keyboard and controllers. Keyboard and controller remapping was added in Patch 1.7 ("The Accessibility Update", PC 2026-04-29), reachable from the Accessibility menu in the Main Menu. An "Invert Stroll" option reverses the stroll button's meaning (see Settings).

Before Patch 1.7 there was no rebinding: a Raw Fury employee said on 2025-04-22 it was "being worked on" and players kept asking through 2025-09.
_source: P1 research 2026-10-31 refs [23] · capture: web_fetch · confidence: medium · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: none_ [Single source -- verify · class:forum]

Remapping is stated for keyboard and controller. Whether the console builds expose the same Remapping entry is not stated by any source read; the PS5 and Xbox builds received the 1.7 content as console update 2.002 (2026-05-06) and Switch 2 got Patch 1.7 around 2026-05-21/22.
_source: P1 research 2026-10-31 refs [11][12][13][14] · capture: web_fetch · confidence: medium · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: none_ [Confirmed: 3 sources, 2 languages]

One article reported that a Game Pass PC copy did not yet have the 1.7 features when it was written ("Game Pass PC players might need to be a bit more patient").
_source: P1 research 2026-10-31 refs [18] · capture: web_fetch · confidence: medium · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: none_ [Single source -- verify · class:editorial-en]

Controller versus mouse (editorial opinion, not a rule): controller movement is described as smoother and more comfortable for long sessions; menus, inventory, entering passwords and terminal codes, and room placement are described as quicker or easier with mouse and keyboard.

Both of those sources date from April 2025, before the Patch 1.7 remapping, so their default-layout descriptions may predate it.

Remapping for keyboard and controller, reached through the Accessibility menu, came with patch 1.7 on PC (2026-04-29), console update 2.002 (2026-05-06, PS5 and Xbox) and Switch 2 version 1.7 (the console notes list the same Invert Stroll option).

## PC (Windows and macOS) -- keyboard and mouse

Defaults as listed by two third-party reference pages (ShortcutPosters is self-described as unofficial; Spottis is undated). Defaults may have changed with the Patch 1.7 remapping and a PC player can rebind any of them.

| Action | Default | tier |
|---|---|---|
| Move | W A S D | none |
| Look / cursor | Mouse | none |
| Interact / confirm | Left mouse button | none |
| Back / cancel | Right mouse button (Esc also, per one page) | none |
| Pause / menu | Esc | none |
| Room Directory | R (the wiki's Room Directory page says "Press R on the estate") | none |

_source: P1 research 2026-10-31 refs [2][21][22] · capture: web_fetch · confidence: medium · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: none_ [Confirmed: 3 sources, 1 languages]

Bindings that only one third-party page lists (single source, verify in game):

| Action | Default | tier |
|---|---|---|
| Map and inventory (Blueprint menu) | Tab | none |
| Journal / blueprints | J | none |
| Stroll toggle | Shift | none |
| Menu navigation | Arrow keys | none |

_source: P1 research 2026-10-31 refs [22] · capture: web_fetch · confidence: medium · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: none_ [Single source -- verify · class:editorial-en]

A Steam player complained that alt-tabbing "constantly toggled the blueprints menu" for their journal, which fits J being a menu key.
_source: P1 research 2026-10-31 refs [23] · capture: web_fetch · confidence: low · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: none_ [Single source -- verify · class:forum]

Two keys name mechanics that are not visible at the start, so they sit one tier up: a "move cart" key (Z, per ShortcutPosters; what the cart is: not stated), and terminal keys (Enter and E; terminals are described as needing the whole A-Z range for passwords).
_source: P1 research 2026-10-31 refs [22][23] · capture: web_fetch · confidence: low · enemy-tier: 1 · puzzle-tier: 1 · category: mainline · spoiler: progression_ [Single source -- verify · class:editorial-en]

Skipping a cinematic is Esc (hold to skip, added around patch 1.4/1.4.6).
_source: P1 research 2026-10-31 refs [1][22] · capture: web_fetch · confidence: medium · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: none_ [Confirmed: 2 sources, 1 languages]

The game's own word is "stroll": the stroll button is the faster movement speed, and the Invert Stroll option makes the faster speed the default (the developer's Patch 1.7 notes and two news pages agree).
_source: P1 research 2026-10-31 refs [1][17][18] · capture: web_fetch · confidence: high · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: none_ [Confirmed: 3 sources, 1 languages]

P2 settles what the two names mean: the third-party "run" label (TrueAchievements and TrueTrophies: "run, though it is more walk faster") and the developer's "stroll" describe the same faster-than-walk speed, which is why Invert Stroll (patch 1.7; the console notes list it too) makes the faster speed the default and the button slows to a normal walk.
_source: P2 research 2026-10-31 refs [7][8][12][17][18][25] · capture: web_fetch · confidence: high · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: none_ [Confirmed: 4 sources, 1 languages]

A cart-pushing key note belongs to a late underground area: W and S push and pull the carts, the arrow keys also work, and on an AZERTY keyboard the Z key failed in April 2025 while W worked (before remapping existed). P1's single-source table lists a "move cart" key as Z; the two accounts are not reconciled.
_source: P2 research 2026-10-31 refs [20] · capture: web_fetch · confidence: low · enemy-tier: 2 · puzzle-tier: 2 · category: mainline · spoiler: late-game_ [Single source -- verify · class:forum]

Keys not found in any source read (gap): every PC binding beyond the rows above. Verified PC keyboard and mouse defaults (the stroll key, the map key) remain a gap after P2.

## PC -- controller

The game recognizes Xbox and DualSense controllers on Steam without third-party tools and runs on Steam Deck. If a controller is not recognized, relaunching with it plugged in is suggested, and enabling Steam Input for the controller in Steam's controller settings is a second suggestion.
_source: https://deltiasgaming.com/can-you-play-blue-prince-with-controller/ ; https://www.sportskeeda.com/esports/should-play-blue-prince-controller-mouse-keyboard · capture: browser_fetch · contributor: setup-wizard Stage 0 · confidence: medium · last-verified: 2026-10-31 · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: none_ [Single source -- verify · class:editorial-en]

The support claim itself is two-source (both pages state it); the troubleshooting steps are single-source. Steam Deck Verified status since 2026-06-03 (Steam news feed).

## PlayStation (PS5, DualSense)

One third-party page (Spottis) lists the layout below; treat it as unreliable. It contradicts the developer's own notes on what stroll does (it says Stroll "reduces movement speed", while the developer's 1.7 notes say the stroll speed is the faster one), and it disagrees with ShortcutPosters on the Blueprint key (R2 here against Tab/J on PC).

| Action | PlayStation | Xbox | tier |
|---|---|---|---|
| Move | Left Stick | Left Stick | none |
| Look / cursor | Right Stick | Right Stick | none |
| Stroll | L2 | LT | none |
| Interact / confirm | Cross | A | none |
| Back | Circle | B | none |
| Use held item | Triangle | Y | none |
| Use special item | Square | X | none |
| Blueprint | R2 | RT | none |
| Room Directory | R1 | RB | none |
| Pause | Options | Menu | none |
| Menu navigation | Left Stick / D-Pad | Left Stick / D-Pad | none |

_source: P1 research 2026-10-31 refs [21] · capture: web_fetch · confidence: low · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: none_ [Contradicted across sources -- see notes]

Player reports (Reddit, 2025-05-04): a PlayStation player ran by holding the left trigger, and replies from Xbox and PlayStation players say the left trigger only needs a tap and toggles run on. So on controllers the left trigger (L2 / LT) is the run toggle, consistent with Shift being the PC toggle.
_source: P1 research 2026-10-31 refs [51] · capture: web_fetch · confidence: medium · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: none_ [Single source -- verify · class:forum]

Other pages describe the controller layout without button names (icons were stripped): left stick walks, right stick looks, one button interacts, one runs ("walk faster"), one opens or closes the inventory (the Blueprint map with inventory, available once you pick up the blueprint), one opens the Room Directory. Which physical button is which: gap. The two pages are from one publisher network, so this counts as one source.
_source: P1 research 2026-10-31 refs [55][56] · capture: web_fetch · confidence: medium · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: none_ [Single source -- verify · class:editorial-en]

P2 reread the same two pages (TrueAchievements, TrueTrophies; one network): the left stick walks and the right stick looks, and four actions are named (interact or open a door, run, open or close the inventory, open the Room Directory) with the button icons stripped from both copies. The TrueAchievements page does not state its platform, so Xbox is only inferred. A search-result summary of the TrueTrophies page said L2 runs and R2 opens the blueprint map, but the icon tokens are not in the copy read; that matches the unreliable Spottis table above (L2 stroll, R2 Blueprint) and the Reddit note that the left trigger is the run toggle, yet it is not a confirmed binding.
_source: P2 research 2026-10-31 refs [12][25] · capture: web_fetch · confidence: low · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: none_ [Hypothesis -- unverified]

PlayStation gap after P2: no confirmed DualSense default bindings (action-to-button assignments). Only the unreliable single table above lists any.

Console remapping: Patch 1.7 is described as adding controller remapping; whether it reached the console builds on the same date is unverified (console update 2.002 = PC 1.7).
