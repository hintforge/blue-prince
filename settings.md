# Blue Prince -- Settings

**status:** research-integrated
**last_reconciled:** 2026-10-31

Organized by the game's in-game menus. Role split with `controls.md`: this file lists the menu entries; `controls.md` owns the key and button bindings and the history of remapping. The exact tab names inside Settings were NOT confirmed by any source (P1 and P2 found none; no live replacement for the removed settings video exists), so the headings below follow the names the sources use and are unverified. Source numbers in brackets are listed in `## Sources`; claims whose `_source:` line says P2 use the P2 numbering listed in `## Sources (P2)`.

## Main menu and system menu

The Main Menu shows Continue (with the current day), New Game, Profiles, Settings and Quit Game. The mid-day system menu shows Resume, Call It a Day, Room Directory, House History and Game Settings. The New Game screen also offers a custom seed of up to 8 digits.

## Controls section of Settings (unverified menu name)

Settings has a controls section with a Smooth Look checkbox (bottom right), mouse sensitivity, a field-of-view slider and invert X/Y axis. Mouse smoothing was on by default at launch (April 2025). One reviewer used a field-of-view value of +11 (an opinion, not a recommended value).

## Accessibility (unverified menu name; Patch 1.7)

Patch 1.7 ("The Accessibility Update", PC 2026-04-29) grouped these features in an Accessibility menu:

| Setting | What the sources say | tier |
|---|---|---|
| Color Assist | Tools for players who have trouble distinguishing some colors: more vivid puzzle colors, plus separate systems for color patterns and for color labels on objects of inquiry. The pages do not use the word "colorblind" as a setting name. | none |
| Remapping | Keyboard and controller key/button remapping. | none |
| Cursor Set | Opacity, style and size of the reticle and cursor; one article describes separate styles for the inactive cursor while moving and the active cursor during puzzles. | none |
| Invert Stroll | Reverses the stroll button: the faster speed becomes the default and the button slows you to a walk. | none |
| Motion Assist | Grouped menu: Cursor/Reticle Settings, Look Sensitivity, Field of View, Smooth Look, Stairs Skip (turns off the visual of the spiral-staircase travel sequence). Each feature is shown with the developer's recommended setting. | none |

Menu path: the Accessibility menu is in the Main Menu (patch 1.7.1 note); two descriptions say it is reached from Settings. No source spells out the exact path from Settings.

Patch 1.7.1 fixed Color Labeling activating without being turned on in the "Color Support Menu"; whether that is the same menu as Color Assist is unconfirmed. The developer does not publish numbers for the recommended values; the menu shows them. P1 only had a search snippet for the cursor options; P2 read the Can I Play That page, which lists them (next paragraph).

Cursor and reticle settings (patch 1.7, PC): a size slider, and separate styles for the inactive cursor (none, subtle cursor, standard cursor, white dot, white cursor) and the active cursor (standard cursor, thicker cursor, white cursor). Color Assist offers color patterns and floating color labels; the Motion Assist group holds Look Sensitivity, Field of View, Smooth Look and Stairs Skip (turns off the spiral-staircase travel visuals); Remapping and Invert Stroll complete the Accessibility menu. Ranges and defaults are not given on either page.
_source: P2 research 2026-10-31 refs [7][8] · capture: web_fetch · confidence: high · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: none_ [Confirmed: 2 sources, 1 languages]

Console update 2.002 also reworked cursor handling for drafting and item pickup and updated the PS5 save-file architecture for size limits (P2, MP1st page summary).
_source: P2 research 2026-10-31 refs [18] · capture: web_fetch · confidence: medium · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: none_ [Single source -- verify · class:editorial-en]

Menu names from Fextralife (P2 repeats P1's): a Profiles menu (restores all four save slots from a backup), Save & Quit, a System Menu with Directory (room details) and History (past house layouts), and the Mount Holly Records and Scrapbook in the Library. P2 found no list of graphics, audio, subtitle or language options and no PS5, Xbox or Switch 2 settings screen.

## Platform notes

Console builds: no differences are documented beyond update numbering and delivery dates; the PS5 save architecture was updated again in 1.7 for save-size limits. Steam Cloud saves and Steam Achievements are listed on the PC store page; Steam Deck Verified since 2026-06-03.

Ultrawide was not supported at launch ("planned feature"); whether that changed was not found.
